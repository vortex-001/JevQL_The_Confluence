Safety & Architecture Guardrails

1. Read-Only Transactions

All custom SQL and ORM queries are executed with explicit read-only transactions, preventing DROP, UPDATE, or DELETE operations.

2. Identifier Quoting (quote_ident)

Schema, table, and column names are validated against the PostgreSQL catalog and safely quoted with psycopg2.sql.Identifier.

3. Session Secret Encryption

Connection credentials for custom databases are stored encrypted in signed HTTP sessions. No database passwords are saved to disk or code.
